# GRP Features

Extracted image features for the GTA Digital GRP project.

This dataset uses `v2.5.6` of the GRP data. Out of `134,447` images in total, `131,470` images were indexed successfully using CLIP.  See the [log file](log.txt) for details.

The `images.csv` has been generated using the query provided in [grp.sparql](grp.sparql).
